## Archivos documentales

- `INFORME_ENTREGABLE6_FINAL.pdf` y `.docx`: informe académico con arquitectura, módulos, patrones, instalación y evidencias registradas.
- `DOCUMENTACION_TECNICA_ENTREGABLE6.pdf`: diagramas, componentes y aspectos técnicos.
- `MANUAL_USUARIO_ENTREGABLE6_FINAL.pdf`: manual de usuario ilustrado con capturas.
- `EVIDENCIAS_NAVEGADOR.zip`: capturas y auditoría visual de las vistas públicas y privadas.

## Código y base de datos

El ZIP final de código deberá generarse desde el commit de la rama de integración para que contenga `gimnasio-frontend/`, `gimnasio-backend/`, `GIMNASIO.sql`, `GIMNASIO_ENTREGABLE6.sql`, `scripts/`, `README.md` y `documentacion/`.

El entorno documentado utiliza Java 17, Spring Boot, React, Vite/Node y MariaDB. Para una base aislada use `scripts/preparar-entregable6.ps1`, cuyo nombre por defecto es `gimnasio_entregable6_test`. No utilizar la base original `gimnasio` para ejecutar tareas de demostración.

## GitHub y presentación

La integración final se realiza mediante Pull Request hacia `main`. Adjuntar capturas de la pestaña Contributors, Pull Requests, Issues y el acta de constitución; estos documentos dependen de los integrantes del equipo.

## Alcance

El informe reúne las evidencias registradas de integración HTTP, navegación, seguridad y pruebas Java, así como las funcionalidades incorporadas y decisiones de diseño. Los horarios y fotografías usados para la demostración no representan necesariamente datos oficiales de un gimnasio real.
